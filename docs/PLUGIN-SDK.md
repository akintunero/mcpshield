# Plugin SDK — @mcpshield/plugin-sdk

The Plugin SDK makes writing a plugin a single-function call. No interfaces
to implement, no event bus to wire, no lifecycle to manage.

## Quick Start

```typescript
// packages/plugins/cloud-digitalocean/src/index.ts
import { createPlugin } from '@mcpshield/plugin-sdk';

export default createPlugin({
  apiVersion: 'v1',
  id: 'cloud-digitalocean',
  name: 'DigitalOcean',
  version: '1.0.0',
  category: 'cloud',
  capabilities: ['discover', 'scan', 'verify'],

  async scan(ctx) {
    ctx.logger.info('Scanning DigitalOcean droplets...');
    const droplets = await listDroplets(ctx.config.apiToken);
    return droplets.map((d) => ({
      id: `do/droplet/${d.id}`,
      title: `Droplet ${d.name} has public IP`,
      severity: 'high',
      resource: { type: 'droplet', id: d.name, location: d.region },
    }));
  },
});
```

## Auto-Generated

| Feature | Auto-generated by SDK |
|---|---|
| Manifest validation | `PluginManifestSchema.parse(manifest)` |
| Capability routing | `createPlugin()` builds handlers map |
| Logging | `ctx.logger` with plugin ID prefix |
| Event publishing | Every capability call emits events |
| Error handling | Wrapped with plugin ID + capability context |
| Timeouts | 5 min default per capability |
| Health checks | Default returns `{ reachable: true }` |
| Compatibility | `VersionCompatibility` checks API version |
| Shutdown | Graceful cleanup on `shutdown()` |

## PluginContext

Every capability handler receives a `PluginContext`:

```typescript
interface PluginContext {
  pluginId: string;
  logger: PluginLogger;
  stateDir: string;        // persistent storage for this plugin
  config: Record<string, unknown>;  // user-provided config
  eventBus: EventBus;
  abortSignal: AbortSignal;  // notified on shutdown
}
```

## Testing

The SDK includes a `testing` module with mocks:

```typescript
import { mock } from '@mcpshield/plugin-sdk/testing';
import myPlugin from './index.js';

const plugin = createPlugin(myPlugin);
const ctx = mock.context();
await plugin.init(ctx);
const findings = await plugin.scan();
expect(findings.length).toBe(3);
```

Also available: `mockFinding()`, `mockEventBus()`, `mockLogger()`.
