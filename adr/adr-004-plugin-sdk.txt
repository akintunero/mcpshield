ADR-004b: Plugin SDK Specification
====================================

The Plugin SDK defines the contract between mcp-core and every plugin.

1. MCPPlugin Interface
-----------------------

Every plugin in packages/plugins/ MUST export a default class implementing
this interface:

```typescript
// packages/sdk/src/plugin.ts

import type { Capability, HealthStatus, Resource, Finding,
  RemediationResult, VerificationResult, PluginManifest } from './manifest.js';

export interface MCPPlugin {
  /** Unique plugin identifier, e.g. "cloud-aws", "kubernetes". */
  readonly id: string;

  /** Loaded plugin manifest. */
  readonly manifest: PluginManifest;

  /** Initialize plugin (called once at startup). */
  init(context: PluginContext): Promise<void>;

  /** List all capabilities this plugin provides. */
  capabilities(): Capability[];

  /** Check connectivity to the target system. */
  health(): Promise<HealthStatus>;

  /** Discover resources (lightweight listing). */
  discover(options?: Record<string, unknown>): Promise<Resource[]>;

  /** Deep scan discovered resources for vulnerabilities. */
  scan(options?: Record<string, unknown>): Promise<Finding[]>;

  /** Execute a remediation action. */
  remediate(finding: Finding): Promise<RemediationResult>;

  /** Verify a finding is resolved. */
  verify(catalogId: string, resourceId: string): Promise<VerificationResult>;

  /** Generate human-readable explanation. */
  explain(finding: Finding): Promise<string>;

  /** Graceful shutdown. */
  shutdown?(): Promise<void>;
}

export interface PluginContext {
  eventBus: EventBus;
  logger: Logger;
  config: Record<string, unknown>;
  stateDir: string;
}
```

2. Capability Model
--------------------

```typescript
// packages/sdk/src/manifest.ts

export interface Capability {
  /** Capability identifier, e.g. "scan.s3.buckets", "remediate.iam.policy" */
  id: string;

  /** Human-readable name. */
  name: string;

  /** Verb: scan | remediate | verify | explain | discover */
  verb: 'scan' | 'remediate' | 'verify' | 'explain' | 'discover';

  /** Resource category this capability applies to. */
  resourceType: string;

  /** Estimated duration for planning purposes. */
  estimatedDuration?: string;
}
```

4. Finding Model
-----------------

Unified finding format across ALL plugins:

```typescript
export interface Finding {
  id: string;                    // unique: "cloud-aws/s3-001/my-bucket"
  pluginId: string;              // which plugin produced this
  capabilityId: string;          // which capability detected it
  title: string;
  description: string;
  severity: 'critical' | 'high' | 'medium' | 'low';
  resource: Resource;
  remediation: {
    summary: string;
    terraform?: string;
    cli?: string;
  };
  evidence: Record<string, unknown>;
  riskScore: number;
  detectedAt: string;
  status: 'open' | 'remediating' | 'resolved';
}
```

5. Plugin Discovery
--------------------

At startup, mcp-core scans packages/plugins/ for directories containing
plugin.json. For each:

  1. Read plugin.json
  2. Validate schema
  3. Import entrypoint (dynamic import)
  4. Call init() with PluginContext
  5. Register capabilities in Capability Registry
  6. Subscribe to relevant events

```typescript
// Discovery algorithm (in mcp-core/src/plugin-registry.ts)

async function discoverPlugins(pluginDirs: string[]): Promise<MCPPlugin[]> {
  const plugins: MCPPlugin[] = [];
  for (const dir of pluginDirs) {
    const manifestPath = join(dir, 'plugin.json');
    if (!existsSync(manifestPath)) continue;
    const manifest = JSON.parse(readFileSync(manifestPath, 'utf8'));
    const pluginModule = await import(join(dir, manifest.entrypoint));
    const plugin: MCPPlugin = new pluginModule.default();
    plugin.manifest = manifest;
    plugins.push(plugin);
  }
  return plugins;
}
```

-------------

```typescript
// packages/sdk/src/events.ts

export type EventType =
  | 'scan.started' | 'scan.completed'
  | 'finding.detected'
  | 'remediation.requested' | 'remediation.approved'
  | 'remediation.executed' | 'remediation.failed'
  | 'verification.completed'

export interface McpEvent {
  type: EventType;
  timestamp: string;
  pluginId?: string;
  data: Record<string, unknown>;

export interface EventBus {
  emit(event: McpEvent): void;
  on(type: EventType, handler: (event: McpEvent) => void): void;
  off(type: EventType, handler: (event: McpEvent) => void): void;
}
```

7. Capability Router
---------------------

```typescript
// packages/mcp-core/src/capability-router.ts

class CapabilityRouter {
  private registry = new Map<string, { plugin: MCPPlugin; cap: Capability }>();

  register(plugin: MCPPlugin): void {
    for (const cap of plugin.capabilities()) {
      this.registry.set(cap.id, { plugin, cap });
    }
  }

  /** Find the best plugin for a given capability verb + resource type. */
  resolve(verb: string, resourceType: string): { plugin: MCPPlugin; cap: Capability } | null {
    for (const [_, entry] of this.registry) {
      if (entry.cap.verb === verb && entry.cap.resourceType === resourceType) {
        return entry;
      }
    }
    return null;
  }

  /** Find all plugins that can handle a resource type. */
  resolveAll(resourceType: string): { plugin: MCPPlugin; cap: Capability }[] {
    const results: { plugin: MCPPlugin; cap: Capability }[] = [];
    for (const [_, entry] of this.registry) {
      if (entry.cap.resourceType === resourceType) {
        results.push(entry);
      }
    }
    return results;
  }
}
```

10. External Plugin Development
--------------------------------

Third-party developers create plugins by:

  1. Create a directory with plugin.json
  2. Install @mcpshield/sdk
  3. Implement MCPPlugin
  4. npm publish
  5. User installs: npm install @mcpshield/plugin-<name>
  6. MCPShield discovers it automatically

No core code changes required.
